你可能也在想

先把这些说清楚。

和普通收藏夹有什么不同？+

Aftermark 想保留的不只是资料，还有你收藏它的意图：想借鉴什么、在哪个项目适用，以及之前哪里用错过。目标是让这些判断真正进入 Agent 的工作过程。

它会把所有收藏都塞给 Agent 吗？+

设计目标是按任务提供少量相关内容，并保留适用范围。普通参考资料不会自动变成必须执行的指令。你可以选择只对当前项目生效。

现在可以安装了吗？+

可以，页面下方提供 v0.1.1 下载和安装步骤。本地版支持笔记、普通网页、文本 PDF、视频链接与字幕，以及任务检索、纠正和使用记录。本页仍为预设演示，不连接真实 Agent。源码和安装步骤见页面底部的 GitHub 链接。

AFTERMARK v0.1.1

从一条真实收藏开始。

需要 Python 3.11+。首次安装联网，日常笔记与检索可离线使用。

1. 下载源码

解压到你自己的文件夹，知识和运行环境都由你掌握。

下载 v0.1.1 ZIP ↗

2. 安装并打开

Windows：先运行 setup.cmd，再运行 start-aftermark.cmd。macOS / Linux：依次运行 sh setup.sh 和 sh start-aftermark.sh。

3. 交给你选择的 Agent

导入示例，尝试一个任务，再到「连接 Agent」复制当前收藏库的配置和工作指引。是否主动调用由客户端与模型决定。
